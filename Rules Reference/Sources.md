## Reliability order

1. Exact text on the relevant component/card in the user's copy.
2. Local rulebook PDF.
3. Direct designer clarification.
4. Well-supported forum compilation or instructional video.
5. Community interpretation/strategy suggestion.

If sources conflict, note the printing/version and follow the highest applicable source above.
