# Stardew Valley Rules Reference

Use these files in this order:

1. [`Quick Reference.md`](Quick%20Reference.md) — fast turn and action lookup.
2. [`Complete Rules.md`](Complete%20Rules.md) — complete searchable rules.
3. [`Clarifications and Edge Cases.md`](Clarifications%20and%20Edge%20Cases.md) — confusing cases and designer/forum rulings.
4. [`Sources.md`](Sources.md) — provenance and reliability order.
5. `Rulebook raw extraction.txt` — searchable fallback extracted directly from the PDF.
6. [`../stardew rules.pdf`](../stardew%20rules.pdf) — authoritative original with diagrams and symbols.

When answering a rules question, check the Complete Rules first, then Edge Cases, and use the PDF/card itself if exact wording or iconography matters.
