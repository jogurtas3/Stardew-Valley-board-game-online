# Išsaugota pagrindinės svetainės kauliukų versija

Tai 2026-07-26 išsaugota veikianti pagrindinės „Stardew Valley“ svetainės kauliukų versija.

Išsaugota:

- 1–3 kauliukų pasirinkimas;
- naudojimo atvejo tekstas pagal kauliukų kiekį;
- simetriškos stalo dalys ir kauliukų išdėstymas;
- kauliukų iššokimo animacija;
- išcentruoti sienelių simboliai;
- visi trys kauliuko simbolių paveikslėliai;
- tikslūs pagrindinės svetainės `index.html` ir `styles.css` failai.

`SHA256SUMS.txt` skirtas patikrinti, ar išsaugoti failai nebuvo pakeisti.

Norint atkurti šią versiją, nukopijuok `index.html`, `styles.css`, `dice-roller.css` ir `dice-roller.js` į `Stardew Valley/Web/`, o `assets` failus – į `Stardew Valley/Web/assets/`.
