# Stardew Dice paruošti paviršiai

Šiame aplanke yra trys vienodo 800 × 800 px dydžio RGB PNG paviršiai, paruošti svetainei tokiu pačiu principu kaip `Animal Dice/Prepared`:

- `dice-junimo.png`
- `dice-stardrop.png`
- `dice-heart.png`

Paviršiai iš naujo iškirpti iš originalių nuotraukų aplanke `../Reference/`. Juodas fonas ir išoriniai kauliuko kraštai neįtraukti, o simbolis su baltu kauliuko paviršiumi užpildo visą kvadratinę tekstūrą.

Tokios pačios 800 × 800 px tekstūros nukopijuotos į `Web/assets/`. Originalūs failai aplanke `Reference/` nepakeisti.
