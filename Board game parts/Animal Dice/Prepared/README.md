# Animal Dice paruošti paviršiai

Šiame aplanke yra šeši vienodo 800 × 800 px dydžio PNG paviršiai, paruošti naudoti tame pačiame 3D CSS kauliuko modelyje kaip „Stardew Dice“:

- `animal-dice-chicken.png`
- `animal-dice-cow.png`
- `animal-dice-duck.png`
- `animal-dice-goat.png`
- `animal-dice-rabbit.png`
- `animal-dice-sheep.png`

Nuo nuotraukų pašalintas juodas fonas. Tos pačios optimizuotos tekstūros nukopijuotos į `Web/assets/`, todėl svetainėje jas galima tiesiogiai priskirti šešioms `.stardew-dice__face` pusėms. Originalios nuotraukos aplanke `Reference/` nepakeistos.

Tikslus fizinių sienelių išdėstymas ir kiekvieno paveikslėlio pasukimo kampas pateiktas `animal-dice-layout.json`. Jis atkurtas pagal visas aštuonias `Reference/corner*.jpg` nuotraukas: front yra cow, back – chicken, right – duck, left – sheep, top – rabbit, o bottom – goat.
